# ManyChat Comment-Trigger Playbook — The Street Architect

**Purpose:** Drive keyword comments on Instagram / TikTok so your ManyChat automation fires.
The automation already works — this doc fixes the *upstream* problem: getting people to comment the keyword in the first place.

**Primary offer:** Zero to BIM — Beginners Guide (free lead magnet)

## The formula (every post)

**Hook (first 3 sec) → deliver value → keyword CTA (last 3–5 sec).**
Reinforce the CTA **3 ways**: said out loud, on-screen text overlay, and first line of the caption.

**3 rules that make triggers actually fire:**
1. Say the keyword out loud AND put it on screen the last 3–5 seconds (85% watch muted).
2. First line of every caption = the CTA: `Comment ZEROBIM 👇`
3. Pin a comment with the keyword yourself right after posting — seeds the behavior.
